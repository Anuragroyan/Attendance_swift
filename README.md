📋 Attendance App

Attendance App is a Swift-based iOS application for managing attendance records using Firebase as the data storage solution. It implements complete CRUD operations, allowing users to create, view, update, and delete attendance records through a simple and intuitive interface.

✨ Features

* 📋 Manage attendance records
* ➕ Create attendance records
* 👀 View attendance data
* ✏️ Update existing records
* 🗑️ Delete attendance records
* 🔥 Firebase integration
* 🔄 Complete CRUD operations
* ☁️ Cloud-based data storage
* 📱 Native iOS interface

🔄 Application Process

Open App → Add Attendance Record → Save to Firebase → View Attendance → Update or Delete Record → Sync Changes with Firebase

🔥 Firebase Integration

Firebase is used to store and manage attendance data in the cloud. The application performs database operations through Firebase whenever users add, retrieve, update, or delete attendance records.

🛠️ Tech Stack

* Swift – iOS application development
* Firebase – Cloud database and data management
* CRUD Operations – Attendance record management
* iOS SDK – Native iOS functionality

🎯 Project Purpose

The project demonstrates how to build an iOS application with Swift and Firebase while implementing complete CRUD functionality. It provides practical experience with cloud data storage, database operations, user input handling, and managing attendance records through a native mobile interface.
